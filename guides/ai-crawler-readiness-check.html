How to check if a website is ready for AI crawlers and agents

Who this is for: SEO and GEO (generative engine optimisation) agencies, site owners and developers who want to know whether ChatGPT, Claude, Perplexity and other AI assistants can reach, read and use a site, and what to change if they can't.

Tools used:

  • Agent-Readiness Auditor | poppy.json, llms.txt & MCP Checker: a 0-100 score from 15 evidence-backed checks, plus ready-to-paste fix files.
  • llms.txt Generator & Checker – AI Crawler Checker & GEO Audit: checks llms.txt and AI-crawler rules, and generates draft llms.txt, llms-full.txt and JSON-LD for each site.

What "AI-ready" means in practice

There is no single standard, so check the signals that AI systems actually use today:

  1. robots.txt rules for AI user agents. Crawlers such as GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot and Google-Extended each read their own User-agent group. A blanket Disallow: / for one of them removes the site from that system.
  2. A firewall or CDN that lets AI agents through. robots.txt can allow a bot while a WAF still blocks it. The Agent-Readiness Auditor requests the homepage with the documented ChatGPT-User user agent and compares the answer with a browser request.
  3. /llms.txt. A Markdown index of the site's key pages, proposed at llmstxt.org.
  4. Content in the raw HTML. Many AI crawlers don't run JavaScript, so a page that only renders client-side can look empty.
  5. schema.org JSON-LD (Organization or LocalBusiness, WebSite, and a page type such as Service, Product or FAQPage).
  6. Agent discovery files for sites that offer an API or agent: an MCP server card, an A2A Agent Card (/.well-known/agent-card.json), OpenAPI or an RFC 9727 /.well-known/api-catalog, and /.well-known/poppy.json (Personal Agent Protocol).

Step 1: Score the sites

Open the Agent-Readiness Auditor, click Try for free, and paste your domains. JSON input:

{
  "domains": ["yourclient.com.au", "https://www.anotherclient.com/pricing", "hello@thirdclient.com"],
  "includeFixSnippets": true,
  "leadThreshold": 50,
  "reportTitle": "AI agent-readiness report"
}

URLs and email addresses are reduced to their domain. Each domain takes roughly 1-5 seconds.

Read the output:

  • Overview view: agentReadinessScore, grade (A 80-100 down to F 0-34), hasLlmsTxt, blockedAiCrawlers, firewallBlocksAiAgents, hasJsonLd, hasMcpDiscovery and topFix.
  • Fixes & snippets view: a prioritised fix list and fixSnippets (a draft llms.txt built from the site's own links, robots.txt lines, Organization JSON-LD and a minimal poppy.json).
  • Key-value store: REPORT_HTML (print to PDF for a client), REPORT_CSV and REPORT_MD.

Checks that a site blocks (401, 403, 429 or a bot challenge) are left out of the score and marked as unverified, never reported as "missing".

Step 2: Generate the llms.txt and JSON-LD deliverables

For sites that need the files written, run the llms.txt Generator & Checker:

{
  "targets": ["https://yourclient.com.au", "https://anotherclient.com"],
  "crawlInternalPages": true,
  "maxInternalPages": 2,
  "generateLlmsTxt": true,
  "generateLlmsFullTxt": true,
  "generateJsonLdSchema": true
}

Each row includes aiGeoReadinessScore, allowedAiCrawlers, blockedAiCrawlers, missingRecommendedJsonLdTypes, identifiedGaps, and the drafts in generatedLlmsTxt, generatedLlmsFullTxt and generatedJsonLdSchema.

Step 3: Apply the fixes

  1. Decide on AI crawler access first. Allowing search and assistant agents (OAI-SearchBot, ChatGPT-User, PerplexityBot, Claude-SearchBot) while blocking training crawlers (GPTBot, ClaudeBot, Google-Extended, CCBot) is a common choice. It is a business decision, so confirm it with the site owner. Example robots.txt lines:
User-agent: OAI-SearchBot
Allow: /

User-agent: GPTBot
Disallow: /
  1. Publish /llms.txt at the site root. Edit the generated draft so it lists the pages you want AI assistants to read first, with one-line descriptions.
  2. Add the JSON-LD to the homepage <head> and check it with Google's Rich Results Test or the Schema.org validator.
  3. Check the firewall. If firewallBlocksAiAgents is true, allow the verified AI user agents in your CDN or WAF bot settings.
  4. Re-run the audit to confirm the score moved.

FAQ

Will an llms.txt file improve my rankings? Nobody can promise that. llms.txt is a proposal, and AI companies don't publish how they use it. It is cheap to publish and gives assistants a clean map of your site, which is why it's worth doing.

Is blocking GPTBot the same as blocking ChatGPT? No. OpenAI documents separate user agents for training (GPTBot), search (OAI-SearchBot) and user-initiated browsing (ChatGPT-User). Check each one.
